# v0.8.0

**It has a notebook of its own now, and about a dozen new tools to fill it.**

Ten new capabilities landed together, and they are all one idea: things Andee keeps for itself rather
than things you asked for — who it is, what it is keeping an eye on, who it knows, what it did today,
and a place to write the work up.

The design and its reasoning, including the parts chosen against, are in
**[docs/design/inner-drive.zh-CN.md](../design/inner-drive.zh-CN.md)** (Chinese).

> **These binaries carry no credentials.** No CodeFlying key, no voice-provider key, and no Google key.
> **You supply your own**: sign up from the link inside the app, then paste the key into
> **Settings → Backend**. Starting is free and the free allowance is finite.
>
> Each package already points at the right server for its language — the English ones at
> `myapp.codeflying.app`, the Chinese at `baas.kuafuai.net`. You do not choose this.
>
> **The macOS packages are signed with a local identity, not an Apple Developer ID**, so Gatekeeper
> refuses the first launch. On macOS 15 the old "right-click → Open" trick no longer exists; see
> **[Opening the Mac app](#opening-the-mac-app)**.

## Highlights

- **A notebook you can read.** 小本本 has five new tabs beside 记忆 / 待办 / 打算, **on both bodies**:
  **自己** (who it is, in its own first-person words), **在意** (what it is keeping an eye on,
  most-overdue first), **日记**, **人** (the people it knows) and **维基** (what it wrote up). On the Mac
  a 维基 row in the timeline carries 打开 › straight to the article.
- **A heartbeat.** About one look every 20 minutes at whether anything it is keeping an eye on has waited
  too long, capped at 40 a day and 6 work turns a day with at least an hour between them. Most looks stop
  at a free gate with no model call at all; nothing overdue costs nothing.
- **动态 (Mac) / the timeline (phone)** — a quiet line for everything that is not conversation: a todo
  waking it, the review and what it folded, its own writes, a thought, bubbles, notifications it let
  pass. 全部 / 只看对话 filters them, and a row with detail opens on click.
- **A tap on the ball stops everything** — the running turn, the queue, and wakes still waiting, plus any
  bubble on screen. One row says what was cut off and what was dropped.
- **A WeChat icon** beside GitHub and Discord, opening Andee's QR code.
- **An out-of-date build is told once at launch** and pointed at CodeFlying. A build *ahead* of the
  release counts as current.
- **Android can speak with the system voice**, so a cloud voice key is no longer required to hear it.

## What's Changed

### Added

- **Its own record, in six parts.** A **self-description** it writes in the first person and rewrites as it
  goes — up to 20 versions kept; **things it cares about**, each with how often it means to look
  (up to 7 active); **a diary**, one page an evening; **the people it knows**, one entry each; **a plan**;
  and **a wiki** for what it wrote up.
- **13 new tools** — `self_note`, `cares`, `diary`, `person`, `people`, and eight `wiki_*`
  (`wiki_search`, `wiki_read`, `wiki_write`, `wiki_show`, `wiki_status`, `wiki_link`, `wiki_share`,
  `wiki_know`).
- **The wiki is plain files, deliberately not encrypted** — it holds work documents, so any editor can
  open them and they can be shared. For the same reason, other people's details belong in the people
  record (encrypted with the notebook) rather than in a wiki page.
- **A heartbeat and work turns.** A work turn has every tool a user's turn has. It touches no screen,
  speaks nothing and sends nothing on your behalf.
- **Heartbeats and bubbles in the timeline**, and a **STOPPED** row when you cut something off.
- **The WeChat QR icon**, on both bodies.

### Changed

- **The default step limit is 40**, up from 25, on both bodies.
- **The settings note describing the heartbeat has been corrected.** It described hours and "while you
  are at the device" that the code no longer has; the actual brakes are the switch, the daily budgets of
  40 looks and 6 work turns with at least an hour between them, and a tap on the ball. Corrected in all
  four language-and-platform files, alongside the same stale wording in the bubble note.

### Fixed

- **A quiet afternoon is one review row, not eighteen.** One stretch of conversation could be reviewed
  four times over — a sweep, the harvest straight after it, and both again after a restart — and every
  write in each became its own row. The Mac now remembers across restarts that a silence was already
  reviewed, a harvest straight after a sweep writes only the hand-over summary, and a review is a single
  row: *"复盘了一遍，记下 N 处"*. A rewrite that changed nothing produces no event at all.
- **When its aim keeps missing, it is now told what to try instead.** On 2026-10-29 the Mac missed a thin
  reply box six times with grid taps and ended up asking the user to click it — while one `tap_target`
  call would have found it. A second coordinate tap that changes nothing, an element-number tap that
  changes nothing, and the same-spot refusal all now name `tap_target` as the next thing to try.
- **A todo paused or closed while its turn was waiting no longer runs**, and a paused plan bubble stays
  paused.
- **Reviews read every memory and pending todo before writing**, so they update rather than duplicate; a
  todo that tries to number several unrelated things is refused.
- **The upgrade link is `codeflying.net/andee` (Chinese) / `codeflying.app/andee` (otherwise)**, and the
  service's own `download_url` is no longer used.
- **Android: 小本本 keeps the picked tab in view** when the card rebuilds; the Mac settings section
  named 小本本 is now **复盘**, which is what it does.

### Opening the Mac app

The `.dmg`s are signed with a local identity, not an Apple Developer ID, so Gatekeeper refuses the first
launch of a downloaded copy.

⚠️ **On macOS 15 (Sequoia) and later, "right-click → Open" no longer works** — Apple removed that
override, and most advice online still recommends it. The current route:

1. Double-click the app. It will be refused. Dismiss the dialog.
2. Open **System Settings → Privacy & Security** and scroll to **Security**.
3. There is a line naming Andee as blocked, with an **Open Anyway** button beside it.
4. Confirm, and authenticate.

That button **only appears for about an hour** after the failed launch. If it is missing, launch the app
again and go straight back to Settings.

One more thing worth knowing: the app **inside** the mounted dmg carries no quarantine flag, so it may
launch straight from the dmg — and then be blocked once you drag it to Applications, which does attach
one. Both behaviours are normal; neither means a damaged download.

### What you supply

No package has a key. After installing, open **Settings → Backend** and either paste a CodeFlying key
(sign up from the link in that panel) or switch to **on-device** and give it an OpenAI-compatible
endpoint and model. A voice key is optional — Android can use the system voice instead, and without any
voice it is silent but still works on screen.

> **Would you rather not configure keys at all?** Use the one-click page instead —
> **[codeflying.app/andee](https://www.codeflying.app/andee)**, or
> **[codeflying.net/andee](https://www.codeflying.net/andee)** in mainland China. Describe what you want,
> tap the build button, and you get a package with the **tokens already configured** plus a QR code to
> scan. Starting is free and the free token allowance is **finite — once it runs out, tokens must be
> bought.** It is a separate service with no direct relationship to this project, with its own terms,
> pricing and data handling. Note it produces **an Android APK, not a Mac app** — macOS packages can
> only be built on macOS.

## Known issues

- **What it keeps for itself is per device.** The one on your phone and the one on your Mac each have
  their own record — their own self-description, their own cares, their own people. They do not share a
  notebook. This is deliberate rather than pending: one individual does not live in two bodies, and it
  avoids cross-device sync, conflicts and doubled budgets as a class of problem. Do not expect the Mac to
  know what the phone was told.
- **Nothing verifies that a key is accepted by the server it is sent to.** These packages are checked for
  the right server and the absence of credentials; whether a given CodeFlying key works against
  `baas.kuafuai.net` versus `myapp.codeflying.app` has not been exercised end-to-end.
- **The Mac still falls back silently when no server is configured.** Every package here carries one, so it
  does not arise for these downloads — but a locally built app with an empty domain resolves to the local
  backend and sends whatever key it has to `api.deepseek.com`, while the self-check reports "Configured".
- **`docs/design/inner-drive.zh-CN.md` still opens with "草案，未实现"** although the classes it describes
  are all present. That status line is the author's to change, so it has been left alone and noted here.
- **The wake threshold's margin is thin**, carried from `v0.3.2`: the eight measured judgements sit in
  1.47–2.05 with the line landing in the gap between 1.69 and 1.77 — 0.08 wide.
- **A light generated page still fades in over a dark stage.** Carried from `v0.3.1`; the app's own
  default has been light since `v0.4.1`.
- **`assets/andee_key.txt` is tracked by git and is not in `.gitignore`.** It ships with a single
  newline, which reads as empty. A key written into it would outrank every build setting.
- Two issues from `v0.1.0` are **unchanged and untouched**: `tools/verify_faces_lab.py` still reports
  7/16 assertions passing, and the debug WebSocket server (`net/BodyWsServer`) still binds
  `0.0.0.0:9008` with no authentication (documented in `SECURITY.md`).

## Before you install

Read **[DISCLAIMER.md](../../DISCLAIMER.md)** and
**[docs/acceptable-use.md](../acceptable-use.md)** first. On Android the app asks for accessibility,
overlay, notification access, SMS and call log, and it can complete a payment by tapping; on the Mac it
asks for accessibility, screen recording and notifications. The only guardrail on that path is Android's
`FLAG_SECURE`; the prompt-level checks on risky actions are instructions to the model, not enforcement.

**It keeps its own record now, and that record is on your device.** The notebook is encrypted with a
key in the platform keystore; the wiki is plain files by design. Anything you would not want in a plain
file should stay in the notebook side.

## Install from source

```bash
git clone https://github.com/kuafuai/andee
cd andee
git checkout v0.8.0

# one variant, by hand:
./gradlew :app:assembleDebug -PdefaultLang=en -PcodeflyingDomain=myapp.codeflying.app -PcodeflyingSsl=true

# or all ten files, the way the release was built:
bash ~/.workbuddy/skills/andee-release-ship/scripts/build_variants.sh
```

`-PcodeflyingKey=` and `-PgoogleVoiceKey=` are refused on purpose — a published package carries no
credential.

There is a getting-started guide: **[docs/getting-started.md](../getting-started.md)**, and
**[docs/getting-started.zh-CN.md](../getting-started.zh-CN.md)** in Chinese.

**Upgrading:** `versionCode` moves `17 → 18`, so the Android package installs over v0.7.1 normally. The
Mac app's version string follows the same number. Existing memory, notebook, todos and chat history are
untouched and are not migrated — the new record is added alongside them, and the notebook gains tabs for
it.
