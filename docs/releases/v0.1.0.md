# v0.1.0

**The first tagged release.** Andee is an individual with a body, not an assistant app: one
`AccessibilityService` is the entry point, there is no main UI, and the tablet is what it wears.

`0.x` is the honest number rather than a modest one — the wire contract a hub brain speaks, the
`local.properties` build flags and the shape of a saved scene all changed inside the first weeks of
work. Treat MINOR versions as able to break. See the [versioning policy](../../CHANGELOG.md#versioning-policy).

> **No APK is attached to this release, on purpose.** The release build type has no `signingConfig`
> and there is no keystore in this repository, so `assembleRelease` emits
> `app-<abi>-release-unsigned.apk`, which will not install until you sign it. Shipping a binary that
> a reader cannot install would be worse than shipping none. Build it yourself —
> see [Install](#install) below.

## Highlights

- **Any app, no integrations.** It reads the screen as a compact element outline and falls back to
  the screenshot when an app draws its own pixels. Every screenshot carries a labelled 8×12 grid and
  it taps by *cell + which third of it* — it never computes coordinates, because general-purpose
  models are bad at that and good at reading them.
- **It types like a keyboard without being one.** On Android 13+ it types through the accessibility
  service's own input channel, into the focused field, **while your own keyboard stays active**.
- **It logs in as you without ever holding your password.** The on-device vault lists accounts and
  has the password *typed* into the focused field; no tool returns it, not even masked.
- **Scenes — ways of working, ready-made or learned.** Four ship under **Scenes → Ready-made
  scenes**, saved only when you tap Adopt. Beyond those it proposes one after the same kind of
  session comes up a few times, and nothing is saved until you say yes.
- **It reads your notifications before they interrupt you**, and stays quiet for groups, newsletters
  and ads.
- **The brain is detachable from the body.** Three mutually exclusive backends: on-device with your
  own key (the out-of-box default), the hosted CodeFlying API market when it is compiled in, or a
  hub reached over a WebSocket.
- **The APK went from ~39 MB to ~8 MB** — an ABI split, `minifyEnabled` + `shrinkResources` on
  release, and deflated native libs. ML Kit's `libbarhopper_v3.so` alone is ~4 MB and the old fat
  APK carried four copies of it.
- **A robot dog counts as a leg.** Through a USB OTG dongle on the same body, so one request can
  move a physical object and look through a camera in a single task.

## What's Changed

### Added

- `docs/architecture.svg` and `docs/architecture.zh-CN.svg`, plus a `## Architecture` section in
  both READMEs — a turn in, the agent loop, six ways out. Drawing it corrected two claims: there are
  three backends rather than two, and an unconfigured device reads as `BRAIN_LOCAL` rather than the
  hosted one.
- A **版本 row in the self-check list** — the first thing this app ever sends anywhere. It asks a
  version service whether a newer build exists: one row, one renderer, no second settings page.
- `LICENSE` — Apache-2.0 with additional conditions. GitHub reports it as `NOASSERTION`; that is
  expected, not a misconfiguration.
- `SECURITY.md`, `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md` + `CONTRIBUTING.zh-CN.md`,
  `DISCLAIMER.md` + `DISCLAIMER.zh-CN.md`, `docs/acceptable-use.md` + `docs/acceptable-use.zh-CN.md`,
  `docs/permissions.md` + `docs/permissions.zh-CN.md`, `THIRD_PARTY_NOTICES.md`.
- A `Signed-off-by:` sign-off is required on every commit, enforced by
  `.github/workflows/dco.yml`.
- Both READMEs now ask for your use case (`## Showcase` / `## 好玩的用法`).

### Changed

- **`assembleRelease` builds again** — it had been failing in `lintVitalRelease` on
  `res/xml/backup_rules.xml` and `res/xml/data_extraction_rules.xml`, both of which exclude
  `domain="device_root"`. A false positive against AGP 8.3's outdated domain list; both lines now
  carry a scoped `tools:ignore`.
- **`SECURITY.md` no longer claims a safeguard the software does not have.** It stated that
  destructive actions are *"gated behind `ask_user` / `confirm` flows"*, which is not true — `ask_user`
  is an ordinary tool the model chooses to call, and nothing forces a confirmation before
  `tap_by_coordinates`. The checks are instructions to the model rather than enforcement.
- **The blanket "no telemetry at all" claim is gone, because the version row made it false.** What
  survives is the half that is still checkable: no analytics SDK, no crash reporting, no event
  tracking, no advertising ID.
- **Positioning corrected throughout the docs** — they described "the body side of a Physical Agent
  system", which contradicts the project's own first instruction: *you are not a tablet's assistant,
  you are an individual, and the tablet is only what carries you.* No code changed; the prose did.
- `README.md` is now the English front page, `README.zh-CN.md` the Chinese one. Every bilingual
  document follows one file per language, and each language links only to its own counterparts.
- `LICENSE` Part A gained a fourth condition: shipping the software inside another product now needs
  written authorisation. Running it yourself, forking it, and charging to support a client who runs
  it themselves all remain permitted.
- `gradle.properties` no longer pins `org.gradle.java.home` to a machine-specific path.

### Fixed

- **A failed voice turn crashed the app with `StackOverflowError` instead of reporting the failure.**
  `AsrController`'s listener implemented `onError(msg)` by calling `onError(msg)` — which resolved to
  *itself*, not the constructor's callback. One recognizer error became infinite recursion. Now
  qualified `this@AsrController.onError(msg)`.

### Removed

- `brain/andee-system-prompt.md` — an unused mirror of the cloud brain's prompt with no runtime role.
  The cloud brain mode itself is not retired.
- The `## 从哪里开始看` section in `README.zh-CN.md`, which held nothing but three rows announcing
  that the demo video and screenshots do not exist yet.

## Before you install

Read **[DISCLAIMER.md](../../DISCLAIMER.md)** and **[docs/acceptable-use.md](../acceptable-use.md)**
first. The uncomfortable part is worth stating plainly here rather than burying it: this app asks for
accessibility, overlay, notification access, SMS and call log, and it can complete a payment by
tapping. The only guardrail on that path is Android's `FLAG_SECURE`. The prompt-level checks on risky
actions are instructions to the model, not enforcement. Assume the device should not be left in a
state where that matters.

## Install

Android 11+ (`minSdk 30`), arm64-v8a for anything bought in the last several years. There is no
binary in this release; build one:

```bash
git clone https://github.com/kuafuai/andee
cd andee
./gradlew :app:assembleDebug      # installs as-is, signed with the debug certificate
```

`assembleRelease` needs your own keystore — the repo has none, so it produces an unsigned APK. The
debug variant ships un-shrunk dex and is larger, which is the price of it installing without you
signing anything. Either way the APK is **per-ABI** (`splits` in `app/build.gradle`), so pick the file
that matches the device.

Full from-scratch setup — the JDK traps, the Android SDK two ways, and a table of the errors you are
likely to hit — is in the README's **Provisioning** section. Then, in this order: grant Overlay → enable
Accessibility → tap the ball → put in your own keys under ⚙.
